# Minimum Size Subarray Sum

Given an array of positive integers and a target sum `s`, find the minimum length of a contiguous subarray whose sum is greater than or equal to `s`.

## Example 1:
**Input:**  
`nums = [2, 3, 1, 2, 4, 3]`, `s = 7`

**Output:**  
`2`

**Explanation:**  
The smallest subarray with sum ≥ 7 is `[4, 3]` (length = 2).

---

## Example 2:
**Input:**  
`nums = [1, 4, 4]`, `s = 4`

**Output:**  
`1`

**Explanation:**  
The smallest subarray with sum ≥ 4 is `[4]` (length = 1).

---

## Example 3:
**Input:**  
`nums = [1, 1, 1, 1, 1, 1, 1, 1]`, `s = 11`

**Output:**  
`0`

**Explanation:**  
There is no subarray whose sum is at least 11.

---

## Example 4:
**Input:**  
`nums = [5, 1, 3, 5, 10, 7, 4, 9, 2, 8]`, `s = 15`

**Output:**  
`2`

**Explanation:**  
The smallest subarray with sum ≥ 15 is `[10, 7]` (length = 2).
